### 🚀 How to Use the Theme

Installing Viper Black is simple through the Visual Studio Code Marketplace.

#### **Method 1: VS Code Extensions View**

1.  Open **Visual Studio Code**.
2.  Go to the Extensions view (`Ctrl+Shift+X` or `Cmd+Shift+X`).
3.  Search for `Viper Black`.
4.  Click **Install**.
5.  After installation, go to **File > Preferences > Theme > Color Theme** (or `Ctrl+K Ctrl+T`).
6.  Select **Viper Black** from the list.

#### **Method 2: Marketplace Link**

1.  Click this link: [Install Viper Black Theme](https://marketplace.visualstudio.com/items?itemName=MightySnake.viper-black)
2.  Click the **Install** button.
